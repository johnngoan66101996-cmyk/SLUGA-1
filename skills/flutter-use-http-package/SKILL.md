## 💡 Что это такое простыми словами
Учит приложение общаться с любыми внешними серверами и API без зависаний при плохом мобильном интернете.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Напиши сервис API с обработкой ошибок сети»
- «Как прикрепить Bearer токен ко всем запросам?»
- «Настрой таймаут запроса и повтор при сбое»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Надежный HTTP-клиент: отправка GET, POST, PUT, DELETE запросов, перехват ошибок сети, таймауты и передача заголовков авторизации.
