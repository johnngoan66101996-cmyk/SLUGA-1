# 🛠️ Навык агента SLUGA: Разработка и Интеграция Моделей SLUGA API (`sluga-api-dev`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** ИИ и Нейросети (Глава 1)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Позволяет агенту SLUGA писать код интеграции нейросетей в ваши программы (на Python, TypeScript, Java, Go), настраивать вызов функций и получать ответы строго в формате JSON без галлюцинаций.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Подключи SLUGA API в мой проект на Python/Node.js»
- «Сделай структурированный вывод JSON по схеме»
- «Настрой вызов функций (function calling) для агента»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Базовый модуль интеграции интеллекта SLUGA в приложения: работа с мультимодальностью (текст, код, изображения, аудио, видео), вызов функций (Function Calling), генерация строгого типизированного JSON по схемам.
