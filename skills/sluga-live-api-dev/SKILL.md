# 🛠️ Навык агента SLUGA: Real-Time Двунаправленный Стриминг Аудио и Видео (SLUGA Live) (`sluga-live-api-dev`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** ИИ и Нейросети (Глава 1)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Дает агенту SLUGA способность говорить и слушать в реальном времени без задержек — как при звонке по телефону, с мгновенной реакцией на прерывания собеседника.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Настрой голосового помощника реального времени»
- «Подключи WebSocket стрим микрофона к SLUGA»
- «Сделай синхронный перевод речи на лету»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Инженерная разработка приложений с мгновенным голосовым и визуальным взаимодействием через двунаправленный WebSocket-протокол SLUGA Live API с детекцией голоса (VAD).
