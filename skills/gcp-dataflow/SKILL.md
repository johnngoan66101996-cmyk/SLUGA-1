# 🛠️ Навык агента SLUGA: Потоковая Обработка Данных Apache Beam на Dataflow (`gcp-dataflow`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Базы данных и Облако (Глава 2)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Инструмент для обработки огромных потоков данных на лету без потери единого сообщения — например, кликов пользователей или транзакций банка.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Напиши пайплайн на Apache Beam (Python/Java)»
- «Устрани отставание потока (System Lag) в Dataflow»
- «Настрой оконную агрегацию (Sliding / Tumbling Windows)»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Разработка отказоустойчивых конвейеров потоковой (Streaming) и пакетной (Batch) обработки данных на Apache Beam с автоскейлингом воркеров в Cloud Dataflow.
