# 🛠️ Навык агента SLUGA: Безопасное Управление Зависимостями Python (`managing-python-dependencies`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Базы данных и Облако (Глава 2)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Следит за тем, чтобы установка новых библиотек не ломала другие программы на вашем компьютере, и чтобы проект запускался у всех без конфликтов версий.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Как правильно добавить новую библиотеку в проект Python?»
- «Настрой виртуальное окружение через uv / venv»
- «Разреши конфликт версий в requirements.txt»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Предотвращение поломки системного окружения: изоляция виртуальных сред (venv, uv, poetry), lock-файлы зависимостей и запрет слепого глобального pip install.
