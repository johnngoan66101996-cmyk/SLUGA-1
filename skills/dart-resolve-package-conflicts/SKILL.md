# 🛠️ Навык агента SLUGA: Разрешение Конфликтов Версий Зависимостей (`dart-resolve-package-conflicts`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Мобильная разработка (Глава 4)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Разруливает сложные конфликты версий библиотек во Flutter-проекте, подбирая совместимые версии или настраивая dependency_overrides.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «pub get падает с ошибкой несовместимости версий»
- «Как использовать dependency_overrides для временного фикса?»
- «Обнови зависимости проекта до актуальных мажоров»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Лечение ошибок 'Because package A depends on B >=1.0.0 and package C depends on B <1.0.0, version solving failed' в pubspec.yaml.
