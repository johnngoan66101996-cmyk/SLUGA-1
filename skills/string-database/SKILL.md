# 🛠️ Навык агента SLUGA: Сети Белок-Белковых Взаимодействий STRING (`string-database`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Наука и Биоинформатика (Глава 7)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Показывает социальную сеть белков в клетке: с кем дружит и с кем взаимодействует конкретный белок для выполнения своих функций.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Построй сеть взаимодействий для списка белков»
- «Какие функциональные пути обогащены в этой группе генов?»
- «Найди прямых партнеров белка p53»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Построение графов белковых взаимодействий (PPI), функциональное обогащение путей (Enrichment) и поиск партнеров по молекулярным комплексам.
