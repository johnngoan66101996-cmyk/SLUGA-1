# 🛠️ Навык агента SLUGA: Генерация Мок-Объектов с Mockito и build_runner (`dart-generate-test-mocks`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Мобильная разработка (Глава 4)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Позволяет тестировать приложение без реального подключения к серверу и без списания реальных денег с тестовых карт.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Сгенерируй MockHttpClient через package:mockito»
- «Как настроить when(mock.getData()).thenAnswer(...)?»
- «Запусти build_runner для обновления моков»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Создание виртуальных копий внешних сервисов (баз данных, платежных шлюзов) для автономного изолированного тестирования.

---

## 💬 Примеры запросов к агенту SLUGA
1. *«SLUGA, примени навык `dart-generate-test-mocks` для текущей задачи в проекте.»*
2. *«Сгенерируй MockHttpClient через package:mockito»*
3. *«Покажи пошаговый план решения с использованием возможностей dart-generate-test-mocks.»*
