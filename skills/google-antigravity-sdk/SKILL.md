# 🛠️ Навык агента SLUGA: Фреймворк Мультиагентных Систем SLUGA SDK (`google-antigravity-sdk`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** ИИ и Нейросети (Глава 1)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Позволяет собирать целые команды виртуальных разработчиков: один пишет код, второй тестирует, третий делает код-ревью под управлением агента SLUGA.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Создай рой из трех агентов для рефакторинга»
- «Настрой агентный пайплайн с памятью»
- «Оркестрация субагентов через Python SDK»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Проектирование, сборка и отладка автономных ИИ-агентов, роевого взаимодействия и графов задач с помощью официального Antigravity SDK.

---

## 💬 Примеры запросов к агенту SLUGA
1. *«SLUGA, примени навык `google-antigravity-sdk` для текущей задачи в проекте.»*
2. *«Создай рой из трех агентов для рефакторинга»*
3. *«Покажи пошаговый план решения с использованием возможностей google-antigravity-sdk.»*
