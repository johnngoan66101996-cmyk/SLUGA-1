# 🛠️ Навык агента SLUGA: Безопасный Протокол Работы с Ключами и Секретами (`credentials`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Инженерная защита (Глава 6)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

---

## 💡 Что это такое простыми словами
Следит за гигиеной безопасности: напоминает положить ключи в файл .env и не дает случайно закоммитить пароли в Git.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Проверь наличие всех необходимых API ключей»
- «Как правильно сохранить токены в файл .env?»
- «Безопасный запрос секретов у пользователя»

---

## ⚙️ Технические возможности и инструменты агента SLUGA
Инструкции по безопасному поиску, проверке наличия и запросу недостающих API-ключей у пользователя без сохранения паролей в открытом коде.

---

## 💬 Примеры запросов к агенту SLUGA
1. *«SLUGA, примени навык `credentials` для текущей задачи в проекте.»*
2. *«Проверь наличие всех необходимых API ключей»*
3. *«Покажи пошаговый план решения с использованием возможностей credentials.»*
