# 🛠️ Навык агента SLUGA: Инженерия Данных с dbt Core / Cloud для BigQuery (`dbt-bigquery`)

> **Исполнитель:** Интеллектуальный агент **SLUGA**  
> **Категория:** Базы данных и Облако (Глава 2)  
> **Режим:** 100% Оффлайн • Локальная работа • Независимый проект

## 💡 Что это такое простыми словами
Золотой стандарт современной инженерии данных: превращает разрозненные SQL-скрипты в профессиональную систему сборки аналитики с контролем версий.

---

## 🎯 Когда агент SLUGA активирует этот навык
Агент автоматически запускает данный регламент при следующих запросах или задачах:
- «Создай dbt-модель для витрины пользователей»
- «Настрой dbt snapshots для отслеживания изменений статусов»
- «Напиши макрос на Jinja для генерации SQL»

## ⚙️ Технические возможности и инструменты агента SLUGA
Разработка аналитических моделей по стандартам dbt (data build tool): Jinja-шаблоны, макросы, snapshot-таблицы истории изменений (SCD Type 2) и CI/CD.
