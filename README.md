# 🤖 Автономный Инженерный ИИ-Агент SLUGA (Серверная часть №1)

> **SLUGA** — это полнофункциональный автономный серверный ИИ-агент, системный архитектор и старший разработчик. Разворачивается на личном сервере (VPS Linux) или локальном ПК, взаимодействует с пользователем через клиентское приложение (псевдо-Телеграм или мобильный клиент), умеет выполнять команды в терминале, писать и редактировать код, искать информацию в сети, обрабатывать голосовые сообщения и документы.

---

## ⚡ Ключевые возможности

- 🛡️ **Защита по Bot Token:** Клиент подключается к серверу исключительно по криптографическому токену связи (`sluga-XXXX-XXXXXX`), предотвращая несанкционированный доступ.
- 🧠 **Официальный шлюз LiteAI ([liteai.tech/docs](https://liteai.tech/docs)):** Работает в РФ напрямую **без VPN**, используя единый баланс для ведущих нейросетей мира (Claude Sonnet 4.6, Opus 4.8, GPT-5.6, DeepSeek, Qwen Coder).
- 🔄 **ReAct-цикл вызова инструментов:** Агент самостоятельно рассуждает, выполняет команды в терминале, читает и создает файлы, проверяет сборки.
- 🩹 **Actor-Critic Self-Healing:** При возникновении ошибок или падении тестов агент не останавливается, а локализует причину, применяет исправление и повторяет задачу до успешного выполнения.
- 🎙️ **Голос и медиа:** Бесплатное распознавание речи (STT) через FFmpeg и озвучка ответов через Microsoft Edge-TTS (`ru-RU-DmitryNeural`).
- 💾 **Долговременная память SQLite WAL:** Сохранение истории диалогов, контекста и журнала самоисцелений.

## 🔑 Архитектура Безопасности и Присвоения Токена

Каждый экземпляр агента SLUGA при первом развертывании генерирует уникальный криптографический идентификатор — **Bot Token**:

```text
Пример токена: sluga-7722-e4a8b1
```

### Принцип работы:
1. **Развертывание:** Вы запускаете установщик `bash setup.sh` на вашем VPS или ПК. Скрипт генерирует токен (или принимает введенный вами) и сохраняет его в локальный секретный файл `.env`.
2. **Привязка клиента:** В интерфейсе клиента (псевдо-Телеграм или мобильное приложение) в меню «Настройки» вы вводите адрес сервера и этот токен.
3. **Защищенный WebSocket:** Клиент подключается по адресу `ws://IP:PORT/ws?token=sluga-XXXX-XXXXXX`. Если токен не совпадает или отсутствует, сервер немедленно сбрасывает сокет с кодом `4003 Forbidden`.
4. **Смена токена:** В любой момент можно сменить токен одной командой:
   ```bash
   python main.py reset-token
   ```

## 🚀 Быстрое Развертывание на Linux VPS (Ubuntu / Debian)

### Шаг 1. Клонирование репозитория
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ_GITHUB>
cd "Слуга№1"
```

### Шаг 2. Запуск автоматического мастера установки
```bash
bash setup.sh
```

Мастер выполнит всё за вас:
- Установит системные пакеты `python3-venv`, `python3-pip`, `ffmpeg`.
- Создаст изолированное виртуальное окружение `.venv` и установит библиотеки.
- Сгенерирует надежный **Bot Token** и сохранит его в `.env`.
- Запросит ваш API-ключ LiteAI (формата `sk-bf-...` с сайта [liteai.tech](https://liteai.tech)).
- Предложит настроить службу **systemd** (`sluga.service`) для круглосуточной работы 24/7 с автозапуском при перезагрузке сервера.
- Выведет на экран готовые параметры для подключения клиента.

### Шаг 3. Управление службой (при установке в systemd)
- Проверить статус: `sudo systemctl status sluga`
- Перезапустить агента: `sudo systemctl restart sluga`
- Посмотреть логи в реальном времени: `sudo journalctl -u sluga -f`

## 💻 Ручной Запуск и Команды CLI

Если вы запускаете агента вручную (на Linux или Windows):

```bash
# Запуск веб-сервера (порт 8080 по умолчанию)
python main.py start

# Просмотр текущего статуса, модели и токена
python main.py status

# Вывод параметров подключения для клиента
python main.py info

# Генерация нового токена связи
python main.py reset-token

# Тест подключения к шлюзу нейросетей LiteAI
python main.py test-ai
```

На Windows доступны готовые сценарии:
- `setup.bat` — первичная установка.
- `start.bat` — запуск сервера.

## 📱 Подключение Клиента (Псевдо-Телеграм)

1. Откройте клиентское приложение SLUGA на вашем ПК или телефоне.
2. Откройте главное меню (иконка ☰ «три полоски») в левом верхнем углу.
3. Перейдите в **«Настройки»** ⚙️.
4. В поле **«Адрес сервера (WebSocket)»** укажите адрес вашего сервера:
   ```text
   ws://<YOUR_SERVER_IP>:8080/ws
   ```
5. В поле **«Токен связи с ботом»** вставьте ваш токен:
   ```text
   sluga-7722-e4a8b1
   ```
6. Нажмите **«Сохранить настройки»**. Индикатор статуса загорится зеленым: **В сети (online)**.

## 🔒 Безопасность

- Файл `.env` и базы данных `data/*.db` включены в `.gitignore` и **никогда не попадут в публичный репозиторий**.
- Любые подключения по WebSocket без корректного токена связи немедленно прерываются.
- Выполнение потенциально опасных команд в терминале защищено проверками и фильтрами.
