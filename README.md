# 🤖 Автономный Инженерный ИИ-Агент SLUGA (Серверная часть №1)

> **SLUGA** — это полнофункциональный автономный серверный ИИ-агент, системный архитектор и старший разработчик. Разворачивается на личном сервере (VPS Linux) или локальном ПК, взаимодействует с пользователем через клиентское приложение (псевдо-Телеграм или мобильный клиент), умеет выполнять команды в терминале, писать и редактировать код, искать информацию в сети, обрабатывать голосовые сообщения и документы.

---

## ⚡ Ключевые возможности

- 🛡️ **Защита по Bot Token:** Клиент подключается к серверу исключительно по криптографическому токену связи (`sluga-XXXX-XXXXXX`), предотвращая несанкционированный доступ.
- 🧠 **Официальный шлюз LiteAI ([liteai.tech/docs](https://liteai.tech/docs)):** Работает в РФ напрямую **без VPN**, используя единый баланс для ведущих нейросетей мира (Claude Sonnet 4.6, Opus 4.8, GPT-5.6, DeepSeek, Qwen Coder).
- 🔄 **ReAct-цикл вызова инструментов:** Агент самостоятельно рассуждает, выполняет команды в терминале, читает и создает файлы, проверяет сборки.
- 🩹 **Actor-Critic Self-Healing:** При возникновении ошибок или падении тестов агент не останавливается, а локализует причину, применяет исправление и повторяет задачу до успешного выполнения.
- 🎙️ **Голос и медиа:** Бесплатное распознавание речи (STT) через FFmpeg и озвучка ответов через Microsoft Edge-TTS (`ru-RU-DmitryNeural`).
- 💾 **Долговременная память SQLite WAL:** Сохранение истории диалогов, контекста и журнала самоисцелений.

## 🔑 Архитектура Безопасности и Присвоения Токена

Каждый экземпляр агента SLUGA при первом развертывании генерирует уникальный криптографический идентификатор — **Bot Token**:

```text
Пример формата токена: sluga-XXXX-XXXXXX (например, sluga-4819-a1b2c3)
```

### Принцип работы:
1. **Развертывание:** Вы запускаете установщик (`bash setup.sh` на Linux или `.\setup.ps1` на Windows). Скрипт генерирует токен (или принимает введенный вами) и сохраняет его в локальный секретный файл `.env`.
2. **Привязка клиента:** В интерфейсе клиента (псевдо-Телеграм или мобильное приложение) в меню «Настройки» вы вводите адрес сервера и этот токен.
3. **Защищенный WebSocket:** Клиент подключается по адресу `ws://IP:PORT/ws?token=sluga-XXXX-XXXXXX`. Если токен не совпадает или отсутствует, сервер немедленно сбрасывает сокет с кодом `4003 Forbidden`.
4. **Смена токена:** В любой момент можно сменить токен одной командой:
   ```bash
   python main.py reset-token
   ```

## 🚀 Установка Одной Строкой (One-Line Setup)

### 🐧 Для Linux / VPS / Серверов (Ubuntu, Debian, SpaceWeb и др.):
Выполните одну команду в терминале сервера:

```bash
git clone https://github.com/johnngoan66101996-cmyk/SLUGA-1.git && cd SLUGA-1 && bash setup.sh
```

### 🪟 Для Windows (PowerShell / Командная строка):
Выполните одну команду в **PowerShell**:

```powershell
git clone https://github.com/johnngoan66101996-cmyk/SLUGA-1.git; cd SLUGA-1; .\setup.ps1
```

*или в классической командной строке **CMD** (Командная строка Windows):*

```cmd
git clone https://github.com/johnngoan66101996-cmyk/SLUGA-1.git && cd SLUGA-1 && setup.bat
```

### 📋 Что делает пошаговый мастер:
- **[Шаг 1]** Проверяет и активирует окружение Python (работает и с `sudo`, и в обычном пользовательском режиме без прав администратора, а на Windows автоматически создает `.venv`).
- **[Шаг 2]** Подготавливает файл конфигурации `.env`.
- **[Шаг 3]** Генерирует или принимает ваш криптостойкий **Bot Token** для защиты сокета.
- **[Шаг 4]** Принимает ваш API-ключ LiteAI и предлагает выбрать модель из меню (напоминаем: **баланс зависит от выбора модели**).
- **[Шаг 5]** Запускает сервер в фоновом режиме или консоли и сразу выводит готовые параметры для подключения в приложении.

- `start.bat` — запуск сервера.

## 📱 Подключение Клиента (SlugaGram на Android и ПК)

Для подключения приложения к серверу доступны **два надежных способа связи**, устраняющих зависимость от локального Wi-Fi:

### Вариант 1: Через собственный домен и Reverse Proxy (Рекомендуется для хостинга / VPS)
* **Как работает:** Хостинг с вашим доменом (например, `your-domain.ru`) принимает входящее защищенное соединение по стандартному порту **443 (HTTPS/WSS)** и перенаправляет его на сокет агента `127.0.0.1:8080`. Порт 443 всегда открыт у всех сотовых операторов (МТС, Билайн, Мегафон) и в любых сетях.
* **Автоматическая настройка:** Скрипт `bash setup.sh` автоматически компилирует правила `.htaccess` для Apache / SpaceWeb или генерирует `nginx_sluga.conf`.
* **В настройках приложения (⚙️):**
  - **Адрес сервера (WebSocket / REST API):** `https://<ВАШ-ДОМЕН>` или `wss://<ВАШ-ДОМЕН>/ws` (например, `https://your-domain.ru`)
  - **Токен связи:** ваш сгенерированный токен `sluga-XXXX-XXXXXX`

### Вариант 2: Через Cloudflare Zero-Trust Tunnel (Без белого IP и без открытия портов)
* **Как работает:** Агент поднимает защищенный исходящий туннель через утилиту `cloudflared`. Подходит для работы на домашнем компьютере или сервере за закрытым фаерволом без статического IP.
* **Автоматическая настройка:** При выборе Варианта 2 в `setup.sh` скрипт создает исполняемый файл `./start_tunnel.sh`, который выдает вам публичный адрес `https://*.trycloudflare.com` или домен Cloudflare.
* **В настройках приложения (⚙️):**
  - **Адрес сервера (WebSocket):** `wss://<CLOUDFLARE_URL>/ws`
  - **Токен связи:** ваш сгенерированный токен `sluga-XXXX-XXXXXX`
